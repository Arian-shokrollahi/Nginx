# installing nginx
---
## ما میتونیم وب سرور nignx رو به روش هایه مختلفی بریزیم ولی بهترین روش روش نصب از مخزن رسمی خوده nginx است. بریم سراغه انواع مدل هایه نصب nginx.
---
## ۱. از طریق مخازن پیش‌فرض اوبونتو (Default APT Repository)
- کاربرد : ساده ترین و سریع ترین روش(نسخه کامپایل شده ، بسیار پایدار اما قدیمی معمولا)
```bash
sudo apt update
sudo apt install nginx
```
---
## ۲. از طریق مخزن رسمی Nginx (Official Nginx PPA / Repository)
- این که همون نسخه ای است که من <mark>پیشنهاد میکنم</mark> 
- **کاربرد:** وقتی که **جدیدترین نسخه پایدار (Stable)** یا **نسخه آزمایشی/اصلی (Mainline)** با آخرین فیچرها و پچ‌های امنیتی را می‌خواهی، اما همچنان می‌خواهی مدیریت آن با `apt` باشد.
- مراحل نصب از طریق مخزت رسمی (برید ببنید از سایت رسمی nginx) :


- 1-آدرس nginx.org رو در مرورگر خود بزنید
- 2-به ادرس بالا که رفتید رو منو سمت چپ که به صورت عمودی است documentation رو انتخاب کنید
- 3- گزینه ی installing nginx رو بزنید
- 4-ا-<mark>3 مدل دارد</mark> 1-ریختن رویه لینوکس & 2-ریختن رویه freeBSD & ساختن از منبع 
- 5-پیشنهاد من رویه لینوکس بزنید 
- 6-صحفه ای که باز میشود به شما میگه که توزیع مورد نظرتون رو انتخاب کنید من ابونتو رو زدم
- 7-از بالا تا پایین دستوراتی که گفته رو میزنید تا بیاد 
```bash
# نصب پیش‌نیازها
sudo apt install curl gnupg2 ca-certificates lsb-release ubuntu-keyring

# دریافت کلید احراز هویت Nginx
curl https://nginx.org/keys/nginx_signing.key | gpg --dearmor \
    | sudo tee /usr/share/keyrings/nginx-archive-keyring.gpg >/dev/null

# اضافه کردن ریپازیتوری Nginx
echo "deb [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] \
http://nginx.org/packages/ubuntu `lsb_release -cs` nginx" \
    | sudo tee /etc/apt/sources.list.d/nginx.list

# آپدیت و نصب
sudo apt update
sudo apt install nginx

```
## ما مخزن **Nginx** (یا هر برنامه‌ی دیگری مثل Docker، NodeSource، PostgreSQL و…) را **یک‌بار** به لیست مخازن اوبونتوی خودمان اضافه می‌کنیم.

از آن لحظه به بعد:

1. **فقط یک‌بار کانفیگ کردی:** مخزن در پوشه `/etc/apt/sources.list.d/` ثبت شده و سیستم آن را تا ابد می‌شناسد.
2. **بروزرسانی مداوم:** هر بار که بزنی `sudo apt update`، سیستم لیست آخرین آپدیت‌ها را از سرور رسمی Nginx می‌گیرد.
3. **ارتقای خودکار:** هر بار که بزنی `sudo apt upgrade`، اگر Nginx نسخه جدیدتری داده باشد، اوبونتو به‌طور خودکار آن را به آخرین نسخه رسمی ارتقا می‌دهد، بدون اینکه نیاز باشد دوباره کاری انجام دهی.

این یکی از بزرگ‌ترین مزیت‌های پکیج‌منیجر `apt` است: **یک‌بار تنظیم مخزن = دریافت همیشگی آخرین نسخه‌ها با دستورات استاندارد لینوکس.**

---
### ۳. با استفاده از داکر / کانتینر (Docker Container)

**کاربرد:** ایزوله‌سازی سرویس، عدم تغییر در سیستم‌عامل میزبان، تست سریع، و اجرای چند سرویس همزمان بدون تداخل پورت یا پکیج.
```bash
# اجرای مستقیم ایمیج رسمی
docker run --name my-nginx -p 80:80 -d nginx
```
---
### ۴. کامپایل و بیلد از سورس‌کد (Building from Source)

**کاربرد:** برای محیط‌های حرفه‌ای/سازمانی که نیاز به **ماژول‌های اختصاصی شخص ثالث (Custom 3rd-party Modules)** مثل `ngx_brotli`، ماژول‌های WAF، یا بهینه‌سازی دقیق در سطح کامپایلر دارند.

مراحل کلی:
```bash
# نصب کامپایلر و وابستگی‌ها
sudo apt update
sudo apt install build-essential libpcre3 libpcre3-dev zlib1g zlib1g-dev libssl-dev

# دانلود سورس و اکسترکت
wget https://nginx.org/download/nginx-1.26.1.tar.gz
tar -zxvf nginx-1.26.1.tar.gz
cd nginx-1.26.1

# کانفیگ و کامپایل
./configure --with-http_ssl_module --with-http_v2_module
make
sudo make install

```
