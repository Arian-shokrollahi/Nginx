## 3-module and directive diffrence
----
#### برایه اینکه داکیومنت رسمی و ساختار  nginx رو خوب بفهمید باید حتما رابطه بین ماژول(module)ودایرکتیو(directive)هارو بفهمی خوب

---
#### **ماژول چیست؟**

یک قطعه کد مستقل (نوشته‌شده به زبان C) است که یک **ویژگی یا عملکرد خاص** را به Nginx اضافه می‌کند. هسته اصلی Nginx به خودی خود کار خاصی انجام نمی‌دهد؛ تمام کارها (پروکسی، SSL، فشرده‌سازی، مدیریت لاگ و …) توسط ماژول‌ها انجام می‌شوند.

### ماژول (Module) در Nginx یعنی چه؟

برخلاف وب‌سرورهایی مثل Apache که سنگین و همه‌چیز-در-خود هستند، معماری Nginx کاملاً **ماژولار (Modular)** و سبک طراحی شده است.

---
### رابطه بین ماژول (Module) و دایرکتیو (Directive)

در داکیومنت رسمی Nginx:

- **ماژول <mark>(Module):</mark> نام «پکیج/فناوری» است.
- **دایرکتیو<mark> (Directive)</mark>:** دستورات و سوییچ‌های تنظیمی داخل فایل کانفیگ هستند که به آن ماژول فرمان می‌دهند.
```bash
┌─────────────────────────────────────────────────────────┐
│ Module: ngx_http_gzip_module (کد برنامه‌نویسی فشرده‌سازی) │
│                                                         │
│   ├─ Directive: gzip on;                                │
│   ├─ Directive: gzip_types text/plain application/json; │
│   └─ Directive: gzip_min_length 1000;                   │
└─────────────────────────────────────────────────────────┘

```

---
## جدول مقایسه ماژول‌های معروف و دایرکتیوهای آنها

| نام ماژول در داکیومنت | عملکرد اصلی | دایرکتیوهای مرتبط و پرکاربرد |
| :--- | :--- | :--- |
| **ngx_http_core_module** | ماژول پایه وب‌سرور، روتینگ و دامنه‌ها | `listen`, `server_name`, `root`, `location`, `try_files` |
| **ngx_http_proxy_module** | تبدیل Nginx به Reverse Proxy (هدایت به Node.js/Python و ...) | `proxy_pass`, `proxy_set_header`, `proxy_read_timeout` |
| **ngx_http_ssl_module** | مدیریت گواهینامه‌های SSL/TLS و پروتکل امن HTTPS | `ssl_certificate`, `ssl_certificate_key`, `ssl_protocols` |
| **ngx_http_gzip_module** | فشرده‌سازی متن، HTML، CSS و پاسخ‌ها برای افزایش سرعت | `gzip`, `gzip_types`, `gzip_min_length`, `gzip_comp_level` |
| **ngx_http_rewrite_module** | ریدایرکت، بازنویسی مسیرها و منطق شرطی (`if`) | `rewrite`, `return`, `set`, `if` |
| **ngx_http_log_module** | تنظیمات لاگ‌های دسترسی (Access Log) | `access_log`, `log_format` |
| **ngx_http_upstream_module** | لودبالانسینگ بین چند سرور بک‌اند | `upstream`, `server`, `ip_hash`, `least_conn` |

---
### مثال دنیای واقعی (سیستم ترمز ماشین) 🚗

1. **ماژول (Module):**قطعه‌ی ترمز ضدقفل (ABS) است که کارخانه روی ماشین نصب کرده است. بدون این قطعه، ماشین اصلاً قابلیت ABS ندارد.
2. **دایرکتیو (Directive):**دکمه‌ی روی داشبورد است که تو با آن می‌گویی: `abs on;` یا `abs off;`.

### مثال واقعی در Nginx (فشرده‌سازی فایل‌ها با Gzip)

فرض کن می‌خواهیم فایل‌های سایت فشرده شوند تا سریع‌تر لود شوند:

1. **ماژول:**
    
    یک فایل برنامه‌نویسی به اسم `ngx_http_gzip_module` است که به زبان C نوشته شده و داخل نرم‌افزار Nginx قرار دارد تا فرمت zip را بفهمد. (تو با این فایل کُد کاری نداری، خودش وجود دارد).
    
2. **دایرکتیو:**
    
    دستوراتی است که تو داخل `nginx.conf` تایپ می‌کنی تا این ماژول روشن شود:

```bash
   gzip on;                        # دایرکتیو اول: روشنش کن
   gzip_types text/plain text/css; # دایرکتیو دوم: این فرمت‌ها رو فشرده کن
```

---
یک نکته‌ی کلیدی که شاید باعث گیج‌شدن شده این است: **«کلمه Module اصلاً در داخل فایل کانفیگ نوشته نمی‌شود!»**

ماژول پشت صحنه است و دایرکتیو جلوی چشم تو در فایل کانفیگ. به قطعه کد زیر نگاه کن:
```bash
http {
    # -------------------------------------------------------------
    # پشت صحنه: ماژول فشرده‌سازی فعال است (ngx_http_gzip_module)
    # -------------------------------------------------------------
    gzip on;                          # <--- این یک Directive است
    gzip_comp_level 5;                # <--- این یک Directive است


    server {
        listen 80;                    # <--- این یک Directive است
        server_name mysite.com;       # <--- این یک Directive است

        # ---------------------------------------------------------
        # پشت صحنه: ماژول پروکسی فعال است (ngx_http_proxy_module)
        # ---------------------------------------------------------
        location /api/ {
            proxy_pass http://127.0.0.1:5000;  # <--- این یک Directive است
            proxy_set_header Host $host;      # <--- این یک Directive است
        }

        # ---------------------------------------------------------
        # پشت صحنه: ماژول مدیریت فایل فعال است (ngx_http_core_module)
        # ---------------------------------------------------------
        location / {
            root /var/www/html;       # <--- این یک Directive است
            index index.html;         # <--- این یک Directive است
        }
    }
}

```
