# 0-befor.start
---
# این قسمت مثل رپو هایه دیگم که بخش 0 برایه مقدمه است رفتیم برای مقدمه 

---
اینو به عنوان پیشنهاد میگم لینوکس و شبکه ای که براتون گذاشتم رو مطالعه کنید و سپس بیاید سراغه این رپو چون پایه فهمیدن nginx  شبکه مقدماتی و لینوکس مقدماتی است پس پایتون رو قوی کنید

---
## چه چیزایی باید قبل از ورود به nginx بلد باشیم
#### ۱. مبانی لینوکس

- [ ] دستور `systemctl` (استارت، استاپ، ری‌لود)
- [ ] دسترسی‌ها: `chmod` و `chown`
- [ ] کاربر `www-data`
- [ ] مسیرهای `/etc/nginx` و `/var/log/nginx`
- [ ] مانیتور لاگ: `tail -f`

---

#### ۲. پروتکل HTTP

- [ ] کدهای `200` و `404`
- [ ] کدهای ریدایرکت: `301` و `302`
- [ ] کدهای خطای سرور: `500`، `502`، `504`
- [ ] هدرهای `Host` و `X-Forwarded-For`
- [ ] تفاوت فایل استاتیک و برنامه داینامیک

---

#### ۳. مفاهیم شبکه

- [ ] پورت‌های `80` (HTTP) و `443` (HTTPS)
- [ ] تفاوت TCP Socket و Unix Socket
- [ ] مفهوم **Reverse Proxy**
- [ ] مفهوم **Load Balancing**
- [ ] رکوردهای DNS (نوع A و CNAME)

---

#### ۴. امنیت و SSL

- [ ] مفهوم کلید عمومی (`.crt`) و خصوصی (`.key`)
- [ ] کار با ابزار **Certbot** (SSL رایگان)

---

#### ۵. ابزارهای ترمینال

- [ ] تست هدرها: `curl -I`
- [ ] بررسی پورت‌های باز: `ss -tulpn`
- [ ] یک ادیتور ساده: `nano` یا `vim`

---
