# 02-nproc command
---
### دستور `nproc` در لینوکس چیست؟

دستور **`nproc`** (مخفف **Number of Processing Units**) یک ابزار ساده و سریع در خط فرمان لینوکس است که **تعداد هسته‌های پردازشی (CPU Cores/Threads)** موجود و در دسترس برای پروسه فعلی را نمایش می‌دهد.

---
### ۱. کاربرد `nproc` در ارتباط با Nginx 

همان‌طور که یاد گرفتیم، برای تنظیم بهترین کارایی در Nginx باید بدانیم سرور چند هسته پردازنده دارد تا مقدار `worker_processes` را تنظیم کنیم.

- اگر دستور `nproc` عدد `4` را برگرداند، یعنی سیستم شما ۴ پردازنده منطقی دارد.
- وقتی در فایل کانفیگ `worker_processes auto;` می‌گذارید، Nginx در پشت صحنه از چیزی شبیه همین دستور استفاده می‌کند تا دقیقاً ۴ عدد Worker Process ایجاد کند.

---

| ویژگی / دستور | توضیحات |
|---|---|
| **نام دستور** | `nproc` (مخفف Number of Processing Units) |
| **کاربرد اصلی** | چاپ تعداد پردازنده‌های منطقی (Cores/Threads) در دسترس |
| **دستور پیش‌فرض** | `nproc` |
| **سوییچ `--all`** | `nproc --all` (نمایش کل هسته‌های فیزیکی نصب‌شده روی مادربورد) |
| **کاربرد در Nginx** | تطبیق با تعداد `worker_processes` برای تقسیم بار بهینه روی CPU |
| **بسته نصبی** | بخشی از پکیج پایه `coreutils` لینوکس (به‌صورت پیش‌فرض نصب است) |

---

## نکته nginx
- وقتی توی فایل کانفیگ می‌نویسی:
```bash
worker_processes auto;
```
- در واقع داری به Nginx می‌گی: «برو به سیستم‌عامل نگاه کن، ببین دقیقاً چند تا هسته پردازشی در دسترسه، و **دقیقاً به همون تعداد Worker Process بساز**.»
--
### ۱. پشت صحنه چه اتفاقی می‌افته؟

مستر پروسس (Master Process) هنگام بالا اومدن با توابع سیستمی هسته لینوکس (کرنل) ارتباط می‌گیره (دقیقاً همون کاری که دستور `nproc` انجام می‌ده) و تعداد Coreها را می‌شماره:

- اگر `nproc` خروجی بده **۲** → ان‌جین‌ایکس **۲ عدد Worker** می‌سازه.
- اگر سرور قوی باشه و `nproc` خروجی بده **۱۶** → ان‌جین‌ایکس **۱۶ عدد Worker** می‌سازه.

--
### ۲. چطور با چشم خودت تستش کنی؟

۱. اول در لینوکس بزن:
```bash
nproc
```
۲. حالا وضعیت پروسه‌های Nginx رو چک کن:
```bash
ps -ef | grep nginx
```
- خروجی چیزی شبیه به این خواهد بود:
```bash
root       1234      1  0 10:00 ?  00:00:00 nginx: master process /usr/sbin/nginx
www-data   1235   1234  0 10:00 ?  00:00:00 nginx: worker process
www-data   1236   1234  0 10:00 ?  00:00:00 nginx: worker process
www-data   1237   1234  0 10:00 ?  00:00:00 nginx: worker process
www-data   1238   1234  0 10:00 ?  00:00:00 nginx: worker process
```
- (می‌بینی که دقیقاً ۱ مستر و ۴ تا ورکر متناظر با خروجی `nproc` ساخته شده).

| مقدار تنظیمی در کانفیگ | رفتار Nginx در سیستم | مزایا / معایب |
|---|---|---|
| `worker_processes auto;` | خواندن تعداد هسته‌ها از سیستم (معادل `nproc`) و ساخت ورکر متناظر | **بهترین حالت (Recommended):** استفاده حداکثری از توان CPU بدون درگیری بیهوده |
| `worker_processes 1;` | فقط ۱ ورکر ساخته می‌شود بدون توجه به تعداد هسته‌ها | فقط از یک هسته استفاده می‌کند؛ بقیه هسته‌ها بیکار می‌مانند |
| `worker_processes 20;` (روی سیستم ۴ هسته‌ای) | ساخت ۲۰ ورکر روی ۴ هسته | **نامناسب:** باعث هدررفت منابع CPU برای سوئیچ مداوم بین ورکرها می‌شود |
